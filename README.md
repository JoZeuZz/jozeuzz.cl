# jozeuzz.cl

Plataforma web personal y de servicios técnicos informáticos. Proyecto nuevo y separado del prototipo histórico [`ProyectoST_Portfolio`](https://github.com/JoZeuZz/ProyectoST_Portfolio).

## Estado

**Fase 0 — Descubrimiento y definición**. Todavía no hay aplicación implementada ni tecnologías aprobadas definitivamente.

Se trabaja en la rama de propuesta `docs/fase-0-definicion` mediante pull request. El alcance, arquitectura y flujo de agentes deben revisarse antes de iniciar el desarrollo.

## Visión

Construir, bajo la identidad `jozeuzz.cl`, un portafolio profesional y una plataforma de servicios técnicos que compartan infraestructura sin mezclar sus flujos de negocio.

## Principios

- Seguridad y autorización desde el diseño.
- Contenido público optimizado para accesibilidad, rendimiento y posicionamiento.
- Gestión de datos personales restringida a usuarios autorizados.
- Arquitectura modular sencilla, sin microservicios prematuros.
- Desarrollo verificable con Git, pruebas y revisión humana.
- Decisiones documentadas y reversibles cuando sea razonable.

La documentación de alcance y arquitectura se propone antes de generar el scaffold técnico.
