# Roadmap — jozeuzz.cl

Todas las fechas y esfuerzos quedan pendientes de planificación. Las fases son incrementales, no compromisos de entrega.

## Fase 0 — Definir antes de desarrollar
- [x] Revisar prototipo anterior y riesgos.
- [x] Crear repositorio nuevo.
- [x] Proponer alcance y alternativas tecnológicas.
- [ ] Confirmar identidad visual, contenido y servicios reales.
- [ ] Implementar POC de compatibilidad Next.js + Payload + PostgreSQL en rama separada.
- [ ] Medir POC, comparar con Astro y registrar ADR aceptado.
- [ ] Confirmar política de privacidad, retención y hosting.

## Fase 1 — Base técnica
- [ ] Scaffold aprobado, locks de dependencias, entornos, Docker.
- [ ] Tests, eslint/typecheck, GitHub Actions, plantillas de PR.
- [ ] Accesos de administrador y roles mínimos, backups y restore verificado.
- [ ] Configuración efectiva de agentes y handoff.

## Fase 2 — MVP público
- [ ] Diseño visual responsive, accesibilidad y páginas profesionales.
- [ ] Proyectos editables, detalle y metadatos.
- [ ] Servicios editables, formularios seguros y panel de solicitudes.
- [ ] E2E principales, observabilidad, SEO y criterios de aceptación.

## Fase 3 — Servicio técnico
- [ ] Clientes, equipos, órdenes de trabajo e historial.
- [ ] Transiciones autorizadas, auditoría y documentos.

## Fase 4 — Producción
- [ ] Revisión de seguridad, restauración, monitoreo, disponibilidad y despliegue.
- [ ] Ajustar funcionalidades futuras según demanda y métricas.
