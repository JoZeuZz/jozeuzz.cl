> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (modo Native elegido por el responsable) con superpowers:test-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> El código de este plan es una **propuesta**: cada paso se verifica con TDD (prueba en rojo por la razón esperada, luego verde). Si una prueba revela que la propuesta es incorrecta, se corrige el código, no la prueba, y se anota la desviación en el commit.

**Goal:** Construir `jz-ai doctor` y `jz-ai skills` (texto y `--json`): una CLI local, determinista y de solo lectura que inventaría skills y diagnostica el entorno sin red, sin ejecutar código inspeccionado y sin leer secretos.

**Architecture:** Paquete independiente en `tools/jz-ai/` sin dependencias. Los comandos reciben un contexto inyectable cuya única puerta al sistema de archivos es una fachada de lectura (`fs-read.js`) y cuya única puerta a procesos es un ejecutor de `git` con lista cerrada (`exec.js`). El análisis (frontmatter, inventario, render) es puro; la E/S se concentra en `discover.js`, `provenance.js`, `git.js` y `doctor.js`.

**Tech Stack:** Node.js ≥ 20.19 (local: 20.19.2), JavaScript ESM, `node:test`, `node:assert/strict`. Sin paquetes npm.

## Global Constraints

- Node `>=20.19`; sin dependencias npm; sólo APIs nativas.
- ESM (`"type": "module"`); identificadores y códigos en inglés; mensajes al usuario en español.
- Sin escrituras persistentes: `src/` y `bin/` no escriben archivos. Salida sólo por stdout/stderr.
- Sin código de red; sin opción `--offline` ni otra para habilitar red.
- Procesos: sólo `/usr/bin/git` validado (regular, ejecutable, uid 0, sin escritura de grupo u otros), nunca buscado en `PATH`, con los argumentos `--version`, `rev-parse --abbrev-ref HEAD` y `rev-parse --verify HEAD` (**sin `git status`**: ejecuta filtros `clean`; el working tree se informa `not-inspected`); `execFile` sin shell; entorno hijo construido desde cero con `PATH=/usr/bin:/bin`, `GIT_OPTIONAL_LOCKS=0`, `GIT_CONFIG_NOSYSTEM=1`, `GIT_CONFIG_GLOBAL=/dev/null`; prefijo `--no-pager -c core.fsmonitor=false -c core.hooksPath=/dev/null`; timeout 5 s; `maxBuffer` 1 MiB.
- Claude Code, OpenCode, skills, plugins y hooks nunca se ejecutan.
- El guard de red de las pruebas es un control de prueba, no un sandbox.
- Contenido leído sólo de: `SKILL.md` en raíces autorizadas (≤ 256 KiB), `~/.agents/.skill-lock.json` y `~/.claude/plugins/installed_plugins.json` (≤ 1 MiB, listas blancas de campos).
- Límites: profundidad de caché de plugins 12; 20 000 entradas de descubrimiento; recuento de hermanos 3 niveles y 1 000 entradas por skill (presupuesto separado); frontmatter 8 192 bytes contando BOM y CRLF; `description` 1 KiB en JSON (el texto no la muestra).
- JSON: `schemaVersion: 1`, claves en el orden documentado, arrays con orden explícito por unidades de código, sin marcas de tiempo; `completeness` ∈ `complete`|`partial`|`failed` (`failed` sólo en el documento de error).
- Saneamiento: `renderJson` aplica `cleanDeep` a todo el documento; el texto usa `cell` en cada celda. `JSON.stringify` no cuenta como saneamiento.
- Errores: nunca se publica `error.message`; sólo códigos validados por `safeErrorCode` y mensajes fijos.
- Severidades: los hallazgos y checks toman la severidad del catálogo de `findings.js`, réplica de las tablas 6.8 y 10.2 de la spec.
- Variables de entorno: definidas = `Object.hasOwn` + tipo cadena, aunque estén vacías. `HOME` se usa sólo si no está vacía y es absoluta.
- Códigos de salida: 0 completo sin errores; 1 parcial o con errores; 2 uso inválido; 3 fallo interno.
- Ningún objetivo de líneas por archivo; un módulo por responsabilidad.
- Los mensajes no incluyen rutas absolutas: las rutas van en `paths` (hallazgos) o en la tabla, donde el texto las abrevia con `~`.
- Los helpers de prueba viven en `test-support/`, fuera de `test/`: Node 20 ejecuta como prueba cualquier `.js` dentro de `test/` (verificado).
- Commits en `feat/jz-ai-m0` con mensajes Conventional Commits en prosa normal.

## Review Focus

1. Nombres de directorio de skill con tabulador, salto de línea o escapes ANSI: la tabla de texto no se rompe y no se inyectan secuencias en la terminal; el JSON conserva el nombre saneado. Prueba en Task 9.
2. `HOME` no definido: `skills` y `doctor` no fallan; emiten `HOME_UNSET` / `env.home-unset`, resultado `partial`, código 1. Pruebas en Task 9 y Task 11.
3. Repositorio Git sin commits: `doctor` informa `repo.head-unavailable` (warn) y `workingTree: not-inspected`, sin código 3. Prueba en Task 10.
4. `SKILL.md` vacío o con bytes no UTF-8: hash calculado, `MANIFEST_INVALID`, sin excepción. Prueba en Task 8.
5. Archivos de procedencia hostiles (`__proto__`, tipos inesperados, arrays en lugar de objetos): no contaminan prototipos ni abortan; producen `PROVENANCE_INVALID` o se ignoran. Prueba en Task 7.
6. Ningún valor del JSON contiene caracteres de control, ANSI o bidi, venga de rutas, nombres, procedencia o errores. Pruebas en Task 1 y Task 9.
7. Frontmatter: el límite de 8 192 bytes cuenta BOM y `\r`; bytes no UTF-8 en el frontmatter producen `invalid-utf8`. Prueba en Task 3.
8. Una skill con miles de archivos no agota el presupuesto de descubrimiento. Prueba en Task 5.
9. `installPath` se compara por ruta canónica. Prueba en Task 7.
10. `git` de `PATH` nunca se ejecuta; `git status` no está en la lista cerrada; un filtro `clean` del repositorio no se ejecuta; los comandos permitidos funcionan con `GIT_CONFIG_GLOBAL=/dev/null`; un repositorio ajeno produce `repo.head-unavailable`. Pruebas en Tasks 10–12.

```js
export function compareText(a, b) {
  if (a === b) return 0;
  if (a === null || a === undefined) return 1;
  if (b === null || b === undefined) return -1;
  return a < b ? -1 : 1;
}

export function compareBy(...keys) {
  return (x, y) => {
    for (const key of keys) {
      const result = compareText(key(x), key(y));
      if (result !== 0) return result;
    }
    return 0;
  };
}
```

`src/sanitize.js`:

```js
const ANSI = /\x1b\[[0-?]*[ -/]*[@-~]|\x1b[@-_]/g;
// C0, DEL, C1 y controles bidireccionales (spec §9).
const CONTROL = /[\x00-\x1f\x7f-\x9f\u200e\u200f\u202a-\u202e\u2066-\u2069]/g;

export function cleanText(value) {
  return String(value).replace(ANSI, '').replace(CONTROL, '');
}

export function cleanDeep(value) {
  if (typeof value === 'string') return cleanText(value);
  if (Array.isArray(value)) return value.map(cleanDeep);
  if (value !== null && typeof value === 'object') {
    return Object.fromEntries(Object.entries(value).map(([key, item]) => [key, cleanDeep(item)]));
  }
  return value;
}

export function cell(value) {
  if (value === null || value === undefined) return '-';
  return String(value)
    .replace(ANSI, '')
    .replace(/\t/g, '\\t')
    .replace(/\r\n|\n|\r/g, '\\n')
    .replace(CONTROL, '');
}

export function redactUrl(url) {
  const text = String(url);
  const match = /^([a-z][a-z0-9+.-]*:\/\/)([^/?#]*)(.*)$/is.exec(text);
  if (!match) return text;
  const [, scheme, authority, rest] = match;
  const at = authority.lastIndexOf('@');
  const host = at === -1 ? authority : `[redacted]@${authority.slice(at + 1)}`;
  return `${scheme}${host}${rest.replace(/\?[^#]*/, '?[redacted]')}`;
}

export function safeErrorCode(error) {
  const code = error?.code;
  return typeof code === 'string' && /^E[A-Z0-9_]{1,31}$/.test(code) ? code : null;
}

export function tildify(path, home) {
  if (!home) return path;
  if (path === home) return '~';
  if (path.startsWith(`${home}/`)) return `~${path.slice(home.length)}`;
  return path;
}
```

```js
  for (const [rel, value] of Object.entries(spec)) {
    const path = join(base, rel);
    await mkdir(dirname(path), { recursive: true });

export async function snapshotTree(base) {
  const out = [];
  async function walk(dir) {
    for (const name of (await readdir(dir)).sort()) {
      const path = join(dir, name);
      const info = await lstat(path);
      const entry = { path: relative(base, path), mode: info.mode, size: info.size, mtimeMs: info.mtimeMs };
      if (info.isSymbolicLink()) entry.link = await readlink(path);
      else if (info.isFile()) entry.sha256 = createHash('sha256').update(await readFile(path)).digest('hex');
      out.push(entry);
      if (info.isDirectory()) await walk(path);
    }

}
```

```js
import { constants, promises as fsp } from 'node:fs';
import { compareText } from './order.js';

const READ_FLAGS = constants.O_RDONLY | constants.O_NOFOLLOW | constants.O_NONBLOCK;

export function createFsRead() {
  return {
    lstat: (path) => fsp.lstat(path),
    realpath: (path) => fsp.realpath(path),
    readdir: async (path) => (await fsp.readdir(path)).sort(compareText),
    readBounded,
  };
}

export async function readBounded(path, maxBytes) {
  const handle = await fsp.open(path, READ_FLAGS);
  try {
    const info = await handle.stat();
    if (!info.isFile()) return { ok: false, reason: 'not-file' };
    if (info.size > maxBytes) return { ok: false, reason: 'too-large' };
    const buffer = Buffer.alloc(maxBytes + 1);
    let total = 0;
    while (total < buffer.length) {
      const { bytesRead } = await handle.read(buffer, total, buffer.length - total, total);
      if (bytesRead === 0) break;
      total += bytesRead;
    }
    if (total > maxBytes) return { ok: false, reason: 'too-large' };
    return { ok: true, bytes: buffer.subarray(0, total) };
  } finally {
    await handle.close();
  }
}
```

```js
export const MAX_FRONTMATTER_BYTES = 8 * 1024;
export const FRONTMATTER_HEAD_BYTES = MAX_FRONTMATTER_BYTES + 1;
const WANTED = new Set(['name', 'description']);
const BOM = Buffer.from([0xef, 0xbb, 0xbf]);
const NEWLINE = 0x0a;
const CR = 0x0d;

export function parseFrontmatter(bytes) {
  // `whole`: el archivo entero cabe en el límite, así que una línea sin \n termina en el fin del archivo.
  const whole = bytes.length <= MAX_FRONTMATTER_BYTES;
  const head = bytes.subarray(0, MAX_FRONTMATTER_BYTES);
  const start = head.subarray(0, 3).equals(BOM) ? 3 : 0;
  const opening = nextLine(head, start, whole);
  if (!opening || !isDelimiter(head, opening)) return failure('missing-opening-delimiter');
  for (let line = nextLine(head, opening.next, whole); line; line = nextLine(head, line.next, whole)) {
    if (!isDelimiter(head, line)) continue;
    let text;
    try {
      text = new TextDecoder('utf-8', { fatal: true }).decode(head.subarray(opening.next, line.start));
    } catch {
      return failure('invalid-utf8');
    }
    return { ok: true, fields: extractFields(text), problem: null };
  }
  return failure('missing-closing-delimiter');
}

function failure(problem) {
  return { ok: false, fields: {}, problem };
}

// Línea [start, end) sin \r\n final; null si no queda una línea completa dentro del límite.
function nextLine(buffer, start, whole) {
  if (start >= buffer.length) return null;
  const newline = buffer.indexOf(NEWLINE, start);
  if (newline === -1 && !whole) return null;
  const stop = newline === -1 ? buffer.length : newline;
  const end = stop > start && buffer[stop - 1] === CR ? stop - 1 : stop;
  return { start, end, next: newline === -1 ? buffer.length : newline + 1 };
}

function isDelimiter(buffer, line) {
  return line.end - line.start === 3 && buffer.toString('latin1', line.start, line.end) === '---';
}

function extractFields(text) {
  const fields = {};
  for (const line of text.split(/\r?\n/)) {
    const match = /^([A-Za-z_][A-Za-z0-9_-]*):[ \t]*(.*)$/.exec(line);
    if (!match || !WANTED.has(match[1]) || Object.hasOwn(fields, match[1])) continue;
    const value = parseScalar(match[2]);
    if (value !== null) fields[match[1]] = value;
  }
  return fields;
}

function parseScalar(raw) {
  const text = raw.trim();
  if (text === '' || /^[|>][+-]?\d*$/.test(text)) return null;
  if (text.startsWith('"')) {
    const match = /^"((?:[^"\\]|\\.)*)"\s*(?:#.*)?$/.exec(text);
    return match ? match[1].replace(/\\(.)/g, '$1') : null;
  }
  if (text.startsWith("'")) {
    const match = /^'((?:[^']|'')*)'\s*(?:#.*)?$/.exec(text);
    return match ? match[1].replace(/''/g, "'") : null;
  }
  if (/^[&*!\[{]/.test(text)) return null;
  return text.replace(/\s+#.*$/, '');
}
```

```js
import { basename, extname, join } from 'node:path';
import { finding } from './findings.js';
import { FRONTMATTER_HEAD_BYTES } from './frontmatter.js';
import { EXCLUDED_DIR_NAMES, SKILL_FILE, isInside, isSensitiveName } from './paths.js';
import { safeErrorCode } from './sanitize.js';

export const LIMITS = Object.freeze({ pluginDepth: 12, maxEntries: 20000, siblingDepth: 3, siblingEntries: 1000, skillBytes: 256 * 1024 });
const SCRIPT_EXTENSIONS = new Set(['.js', '.cjs', '.mjs', '.ts', '.sh', '.bash', '.py', '.rb', '.pl']);

export async function discoverSkills(ctx, roots, limits = LIMITS) {
  const state = { entries: 0, limitHit: false, depthLimitRoots: new Set(), partial: false, findings: [], manifests: [] };
  const probed = [];
  for (const root of roots) probed.push(await probeRoot(ctx.fs, root, state));
  const authorized = probed.filter((root) => root.status === 'ok').map((root) => root.realPath);
  for (const root of probed) {
    if (root.status !== 'ok') continue;
    if (root.layout === 'entries') await scanEntries(ctx, root, authorized, state, limits);
  }
  return {
    roots: probed.map(({ id, host, path, realPath, status }) => ({ id, host, path, realPath, status })),
    manifests: state.manifests,
    findings: state.findings,
    partial: state.partial,
  };
}

async function probeRoot(fs, root, state) {
  let realPath;
  try {
    realPath = await fs.realpath(root.path);
  } catch (error) {
    if (error.code === 'ENOENT' || error.code === 'ENOTDIR') {
      state.findings.push(finding('ROOT_MISSING', root.id, [root.path], 'La raíz no existe.'));
      return { ...root, realPath: null, status: 'missing' };
    }
    return unreadableRoot({ ...root, realPath: null }, error, state);
  }
  try {
    const info = await fs.lstat(realPath);
    if (!info.isDirectory()) {
      state.findings.push(finding('ROOT_NOT_DIRECTORY', root.id, [root.path], 'La raíz no es un directorio.'));
      return { ...root, realPath, status: 'not-directory' };
    }
  } catch (error) {
    return unreadableRoot({ ...root, realPath }, error, state);
  }
  return { ...root, realPath, status: 'ok' };
}

function unreadableRoot(root, error, state) {
  state.partial = true;
  state.findings.push(finding('UNREADABLE', root.id, [root.path], `No se pudo leer la raíz (${safeErrorCode(error) ?? 'error'}).`));
  return { ...root, status: 'unreadable' };
}

function tick(state, limits, subject, path) {
  state.entries += 1;
  if (state.entries <= limits.maxEntries) return true;
  if (!state.limitHit) {
    state.limitHit = true;
    state.partial = true;
    state.findings.push(finding('LIMIT_REACHED', subject, [path], `Se alcanzó el límite de ${limits.maxEntries} entradas.`));
  }
  return false;
}

async function listDir(ctx, dir, subject, state) {
  try {
    return await ctx.fs.readdir(dir);
  } catch (error) {
    state.partial = true;
    state.findings.push(finding('UNREADABLE', subject, [dir], `No se pudo listar el directorio (${safeErrorCode(error) ?? 'error'}).`));
    return [];
  }
}

async function lstatEntry(ctx, path, subject, state) {
  try {
    return await ctx.fs.lstat(path);
  } catch (error) {
    if (error.code === 'ENOENT' || error.code === 'ENOTDIR') return null;
    state.partial = true;
    state.findings.push(finding('UNREADABLE', subject, [path], `No se pudo inspeccionar (${safeErrorCode(error) ?? 'error'}).`));
    return null;
  }
}

async function scanEntries(ctx, root, authorized, state, limits) {
  for (const name of await listDir(ctx, root.realPath, root.id, state)) {
    if (EXCLUDED_DIR_NAMES.has(name)) continue;
    const physical = join(root.realPath, name);
    if (!tick(state, limits, root.id, physical)) return;
    const info = await lstatEntry(ctx, physical, name, state);
    if (!info) continue;
    const entryDir = join(root.path, name);
    if (info.isDirectory()) {
      await readSkillDir(ctx, { root, entryDir, dir: physical, linkTarget: null, plugin: null }, authorized, state, limits);
    } else if (info.isSymbolicLink()) {
      const target = await resolveEntryLink(ctx, root, name, physical, entryDir, authorized, state);
      if (target) await readSkillDir(ctx, { root, entryDir, dir: target, linkTarget: target, plugin: null }, authorized, state, limits);
    }
  }
}

async function resolveEntryLink(ctx, root, name, physical, entryDir, authorized, state) {
  let target;
  try {
    target = await ctx.fs.realpath(physical);
  } catch (error) {
    if (error.code === 'ENOENT') {
      state.findings.push(finding('BROKEN_LINK', name, [entryDir], 'El enlace apunta a una ruta inexistente.'));
    } else if (error.code === 'ELOOP') {
      state.findings.push(finding('LINK_CYCLE', name, [entryDir], 'El enlace forma un ciclo.'));
    } else {
      state.partial = true;
      state.findings.push(finding('UNREADABLE', name, [entryDir], `No se pudo resolver el enlace (${safeErrorCode(error) ?? 'error'}).`));
    }
    return null;
  }
  if (authorized.includes(target) || isInside(root.realPath, target)) {
    state.findings.push(finding('LINK_CYCLE', name, [entryDir, target], 'El enlace apunta a una raíz o a un ancestro de la entrada.'));
    return null;
  }
  if (!authorized.some((base) => isInside(target, base))) {
    state.findings.push(finding('LINK_OUTSIDE_ROOTS', name, [entryDir, target], 'El enlace sale de las raíces autorizadas; no se lee.'));
    return null;
  }
  const info = await lstatEntry(ctx, target, name, state);
  if (!info) return null;
  if (!info.isDirectory()) {
    state.findings.push(finding('ENTRY_NOT_DIRECTORY', name, [entryDir, target], 'El enlace de entrada no apunta a un directorio.'));
    return null;
  }
  return target;
}

async function readSkillDir(ctx, entry, authorized, state, limits) {
  const { root, entryDir, dir } = entry;
  const subject = basename(entryDir);
  const skillPath = join(dir, SKILL_FILE);
  const info = await lstatEntry(ctx, skillPath, subject, state);
  if (!info) return;
  const manifest = {
    rootId: root.id,
    host: root.host,
    entryPath: join(entryDir, SKILL_FILE),
    realPath: skillPath,
    linkTarget: entry.linkTarget,
    dirName: subject,
    plugin: entry.plugin,
    head: null,
    sha256: null,
    size: null,
    readProblem: null,
    siblingFiles: 0,
    scriptLike: false,
  };
  let filePath = skillPath;
  if (info.isSymbolicLink()) {
    const resolved = await resolveManifestLink(ctx, manifest, skillPath, authorized, state);
    if (!resolved) {
      state.manifests.push(manifest);
      return;
    }
    filePath = resolved;
    manifest.realPath = resolved;
  } else if (!info.isFile()) {
    manifest.readProblem = 'not-file';
    state.findings.push(finding('ENTRY_NOT_FILE', subject, [manifest.entryPath], 'El manifiesto no es un archivo regular.'));
    state.manifests.push(manifest);
    return;
  }
  await readManifestFile(ctx, manifest, filePath, state, limits);
  await countSiblings(ctx, dir, 0, manifest, { used: 0, truncated: false }, state, limits);
  state.manifests.push(manifest);
}

async function resolveManifestLink(ctx, manifest, skillPath, authorized, state) {
  const subject = manifest.dirName;
  let target;
  try {
    target = await ctx.fs.realpath(skillPath);
  } catch (error) {
    manifest.readProblem = 'broken-link';
    const code = error.code === 'ELOOP' ? 'LINK_CYCLE' : 'BROKEN_LINK';
    state.findings.push(finding(code, subject, [manifest.entryPath], 'El enlace del manifiesto no se puede resolver.'));
    return null;
  }
  if (isSensitiveName(basename(target))) {
    manifest.readProblem = 'sensitive';
    state.findings.push(finding('SENSITIVE_PATH_SKIPPED', subject, [manifest.entryPath, target], 'El manifiesto enlaza a un archivo sensible; no se lee.'));
    return null;
  }
  if (basename(target) !== SKILL_FILE || !authorized.some((base) => isInside(target, base))) {
    manifest.readProblem = 'outside-roots';
    state.findings.push(finding('LINK_OUTSIDE_ROOTS', subject, [manifest.entryPath, target], 'El manifiesto enlaza fuera de las raíces autorizadas; no se lee.'));
    return null;
  }
  return target;
}

async function readManifestFile(ctx, manifest, filePath, state, limits) {
  let result;
  try {
    result = await ctx.fs.readBounded(filePath, limits.skillBytes);
  } catch (error) {
    manifest.readProblem = 'unreadable';
    state.partial = true;
    state.findings.push(finding('UNREADABLE', manifest.dirName, [manifest.entryPath], `No se pudo leer el manifiesto (${safeErrorCode(error) ?? 'error'}).`));
    return;
  }
  if (!result.ok) {
    manifest.readProblem = result.reason;
    if (result.reason === 'too-large') {
      state.findings.push(finding('TOO_LARGE', manifest.dirName, [manifest.entryPath], `El manifiesto supera ${limits.skillBytes} bytes; no se analiza.`));
    } else {
      state.findings.push(finding('ENTRY_NOT_FILE', manifest.dirName, [manifest.entryPath], 'El manifiesto no es un archivo regular.'));
    }
    return;
  }
  manifest.size = result.bytes.length;
  manifest.sha256 = createHash('sha256').update(result.bytes).digest('hex');
  // Copia de la cabecera: el resto del contenido no sale de esta función.
  manifest.head = Buffer.from(result.bytes.subarray(0, FRONTMATTER_HEAD_BYTES));
}

// Presupuesto propio por skill: no consume `maxEntries` ni marca el resultado como parcial.
async function countSiblings(ctx, dir, depth, manifest, budget, state, limits) {
  for (const name of await listDir(ctx, dir, manifest.dirName, state)) {
    if ((depth === 0 && name === SKILL_FILE) || EXCLUDED_DIR_NAMES.has(name)) continue;
    if (budget.used >= limits.siblingEntries) {
      if (!budget.truncated) {
        budget.truncated = true;
        state.findings.push(finding('SIBLINGS_TRUNCATED', manifest.dirName, [manifest.entryPath],
          `Recuento detenido en ${limits.siblingEntries} entradas: siblingFiles es una cota inferior y scriptLike puede ser un falso negativo.`));
      }
      return;
    }
    budget.used += 1;
    const path = join(dir, name);
    const info = await lstatEntry(ctx, path, manifest.dirName, state);
    if (!info) continue;
    if (info.isDirectory()) {
      if (depth + 1 < limits.siblingDepth) await countSiblings(ctx, path, depth + 1, manifest, budget, state, limits);
      continue;
    }
    manifest.siblingFiles += 1;
    if (SCRIPT_EXTENSIONS.has(extname(name).toLowerCase()) || (info.isFile() && (info.mode & 0o111) !== 0)) manifest.scriptLike = true;
  }
}
```

```js
async function walkPluginDir(ctx, root, dir, depth, authorized, state, limits) {
  const names = await listDir(ctx, dir, root.id, state);
  if (names.includes(SKILL_FILE)) {
    const entryDir = join(root.path, relative(root.realPath, dir));
    await readSkillDir(ctx, { root, entryDir, dir, linkTarget: null, plugin: pluginFromPath(root, dir) }, authorized, state, limits);
  }
  for (const name of names) {
    if (name === SKILL_FILE || EXCLUDED_DIR_NAMES.has(name)) continue;
    const path = join(dir, name);
    if (!tick(state, limits, root.id, path)) return;
    const info = await lstatEntry(ctx, path, root.id, state);
    if (!info) continue;
    if (info.isSymbolicLink()) {
      state.findings.push(finding('SYMLINK_NOT_FOLLOWED', root.id, [path], 'Symlink dentro de la caché de plugins; no se sigue.'));
      continue;
    }
    if (!info.isDirectory()) continue;
    if (depth + 1 > limits.pluginDepth) {
      reportDepthLimit(root, path, state, limits);
      continue;
    }
    await walkPluginDir(ctx, root, path, depth + 1, authorized, state, limits);
  }
}

function reportDepthLimit(root, path, state, limits) {
  state.partial = true;
  if (state.depthLimitRoots.has(root.id)) return;
  state.depthLimitRoots.add(root.id);
  state.findings.push(finding('LIMIT_REACHED', root.id, [path], `Directorio a más de ${limits.pluginDepth} niveles; no se recorre.`));
}

function pluginFromPath(root, dir) {
  const parts = relative(root.realPath, dir).split(sep);
  if (parts.length < 3 || parts[0] === '') return null;
  const [marketplace, name, cacheVersion] = parts;
  return { marketplace, name, cacheVersion, versionDir: join(root.realPath, marketplace, name, cacheVersion) };
```

```js
import { isAbsolute, relative, sep } from 'node:path';
import { finding } from './findings.js';
import { isInside } from './paths.js';
import { cleanText, redactUrl, safeErrorCode } from './sanitize.js';

export const MAX_PROVENANCE_BYTES = 1024 * 1024;
export const LOCK_FIELDS = ['source', 'sourceType', 'sourceUrl', 'skillPath', 'skillFolderHash', 'installedAt', 'updatedAt'];
export const PLUGIN_FIELDS = ['scope', 'installPath', 'version', 'gitCommitSha', 'installedAt', 'lastUpdated'];

export async function loadProvenance(ctx, files) {
  const findings = [];
  const lockJson = await readJsonFile(ctx, files.skillLock, 'skill-lock', findings);
  const pluginsJson = await readJsonFile(ctx, files.installedPlugins, 'installed-plugins', findings);
  return {
    skillLock: lockJson === null ? null : parseSkillLock(lockJson, files.skillLock, findings),
    plugins: pluginsJson === null ? null : await parseInstalledPlugins(ctx, pluginsJson, files.installedPlugins, findings),
    findings,
  };
}

async function readJsonFile(ctx, path, subject, findings) {
  if (!path) return null;
  let result;
  try {
    result = await ctx.fs.readBounded(path, MAX_PROVENANCE_BYTES);
  } catch (error) {
    if (error.code !== 'ENOENT') findings.push(invalid(subject, path, `No se pudo leer (${safeErrorCode(error) ?? 'error'}).`));
    return null;
  }
  if (!result.ok) {
    findings.push(invalid(subject, path, result.reason === 'too-large' ? `Supera ${MAX_PROVENANCE_BYTES} bytes.` : 'No es un archivo regular.'));
    return null;
  }
  try {
    return JSON.parse(result.bytes.toString('utf8'));
  } catch {
    findings.push(invalid(subject, path, 'JSON inválido.'));
    return null;
  }
}

function invalid(subject, path, message) {
  return finding('PROVENANCE_INVALID', subject, [path], message);
}

function parseSkillLock(json, path, findings) {
  if (!isPlainObject(json) || !isPlainObject(json.skills)) {
    findings.push(invalid('skill-lock', path, 'Estructura inesperada: falta el objeto "skills".'));
    return null;
  }
  const map = new Map();
  for (const [name, value] of Object.entries(json.skills)) {
    if (isPlainObject(value)) map.set(name, pick(value, LOCK_FIELDS));
  }
  return map;
}

async function parseInstalledPlugins(ctx, json, path, findings) {
  if (!isPlainObject(json) || !isPlainObject(json.plugins)) {
    findings.push(invalid('installed-plugins', path, 'Estructura inesperada: falta el objeto "plugins".'));
    return null;
  }
  const map = new Map();
  for (const [id, value] of Object.entries(json.plugins)) {
    if (!Array.isArray(value)) continue;
    const entries = [];
    for (const raw of value.filter(isPlainObject)) {
      const entry = pick(raw, PLUGIN_FIELDS);
      entries.push({ ...entry, installRealPath: await canonicalPath(ctx, entry.installPath) });
    }
    map.set(id, entries);
  }
  return map;
}

// realpath es metadata: resuelve componentes sin abrir el destino.
async function canonicalPath(ctx, path) {
  if (!path || !isAbsolute(path)) return null;
  try {
    return await ctx.fs.realpath(path);
  } catch {
    return null;
  }
}

function pick(source, fields) {
  const out = {};
  for (const field of fields) {
    const value = Object.hasOwn(source, field) ? source[field] : undefined;
    out[field] = typeof value === 'string' ? cleanText(field === 'sourceUrl' ? redactUrl(value) : value) : null;
  }
  return out;
}

function isPlainObject(value) {
  return value !== null && typeof value === 'object' && !Array.isArray(value);
}

export function lockEntryFor(manifest, agentsRoot, skillLock) {
  if (!skillLock || !agentsRoot || !isInside(manifest.realPath, agentsRoot)) return null;
  const [name] = relative(agentsRoot, manifest.realPath).split(sep);
  const entry = skillLock.get(name);
  return entry ? { kind: 'skill-lock', ...entry } : null;
}

export function pluginRecord(plugin, plugins) {
  if (!plugin) return null;
  const id = `${plugin.name}@${plugin.marketplace}`;
  const entries = plugins ? plugins.get(id) ?? [] : null;
  const match = entries?.find((entry) => entry.installRealPath !== null && entry.installRealPath === plugin.versionDir);
  return {
    id,
    marketplace: plugin.marketplace,
    name: plugin.name,
    cacheVersion: plugin.cacheVersion,
    installed: entries === null ? 'unknown' : match ? 'yes' : 'no',
    enabled: 'unknown',
    loaded: 'unverified',
    registry: match ? { version: match.version, gitCommitSha: match.gitCommitSha, installedAt: match.installedAt, lastUpdated: match.lastUpdated } : null,
  };
}
```

```js
import { finding } from './findings.js';
import { parseFrontmatter } from './frontmatter.js';
import { compareBy, compareText } from './order.js';
import { lockEntryFor, pluginRecord } from './provenance.js';
import { cleanText } from './sanitize.js';

const DESCRIPTION_LIMIT = 1024;

export function buildInventory({ manifests, provenance, agentsRoot }) {
  const findings = [];
  const skills = manifests
    .map((manifest) => toSkillRecord(manifest, provenance, agentsRoot, findings))
    .sort(compareBy((s) => s.name, (s) => s.rootId, (s) => s.entryPath));
  const groups = buildGroups(skills, findings);
  addPluginFindings(skills, findings);
  return { skills, groups, findings };
}

function toSkillRecord(m, provenance, agentsRoot, findings) {
  const manifest = { valid: false, problems: [] };
  let name = null;
  let nameSource = 'directory';
  let description = null;
  if (m.head !== null) {
    const parsed = parseFrontmatter(m.head);
    if (!parsed.ok) manifest.problems.push(parsed.problem);
    else if (!parsed.fields.name) manifest.problems.push('missing-name');
    else {
      name = cleanText(parsed.fields.name);
      nameSource = 'frontmatter';
    }
    if (parsed.ok && parsed.fields.description) description = cleanText(parsed.fields.description).slice(0, DESCRIPTION_LIMIT);
    manifest.valid = manifest.problems.length === 0;
  } else {
    manifest.problems.push(`not-read:${m.readProblem}`);
  }
  if (!name) {
    name = cleanText(m.dirName);
    nameSource = 'directory';
  }
  if (m.head !== null && !manifest.valid) {
    findings.push(finding('MANIFEST_INVALID', name, [m.entryPath], `Manifiesto inválido: ${manifest.problems.join(', ')}.`));
  }
  if (nameSource === 'frontmatter' && name !== m.dirName) {
    findings.push(finding('MANIFEST_NAME_MISMATCH', name, [m.entryPath], `El nombre del frontmatter no coincide con el directorio "${m.dirName}".`));
  }
  return {
    name,
    nameSource,
    description,
    rootId: m.rootId,
    host: m.host,
    entryPath: m.entryPath,
    realPath: m.realPath,
    linkTarget: m.linkTarget,
    sha256: m.sha256,
    size: m.size,
    siblingFiles: m.siblingFiles,
    scriptLike: m.scriptLike,
    manifest,
    plugin: pluginRecord(m.plugin, provenance.plugins),
    provenance: lockEntryFor(m, agentsRoot, provenance.skillLock),
    availability: 'unverified',
  };
}

function buildGroups(skills, findings) {
  const byName = new Map();
  for (const skill of skills) {
    if (!byName.has(skill.name)) byName.set(skill.name, []);
    byName.get(skill.name).push(skill);
  }
  const groups = [];
  for (const [name, members] of [...byName].sort((a, b) => compareText(a[0], b[0]))) {
    const variantMap = new Map();
    for (const skill of members) {
      if (!variantMap.has(skill.sha256)) variantMap.set(skill.sha256, { sha256: skill.sha256, realPaths: new Set(), entryPaths: [] });
      const variant = variantMap.get(skill.sha256);
      variant.realPaths.add(skill.realPath);
      variant.entryPaths.push(skill.entryPath);
    }
    const variants = [...variantMap.values()]
      .map((v) => ({ sha256: v.sha256, realPaths: [...v.realPaths].sort(compareText), entryPaths: v.entryPaths.sort(compareText) }))
      .sort((a, b) => compareText(a.sha256, b.sha256));
    const hashes = variants.filter((v) => v.sha256 !== null);
    const incomplete = hashes.length !== variants.length;
    const realPaths = [...new Set(members.map((s) => s.realPath))].sort(compareText);
    let status;
    if (hashes.length > 1) status = 'divergent';
    else if (members.length === 1) status = 'single';
    else if (realPaths.length === 1) status = 'aliased';
    else if (incomplete) status = 'undetermined';
    else status = 'identical';
    groups.push({ name, status, incomplete, variants });

    if (status === 'divergent') {
      const short = hashes.map((v) => v.sha256.slice(0, 8)).join(', ');
      findings.push(finding('NAME_COLLISION_DIVERGENT', name, members.map((s) => s.entryPath),
        `${hashes.length} variantes de contenido: ${short}. El mismo nombre no implica que el host cargue la misma skill.`));
    }
    if (status === 'identical') {
      findings.push(finding('NAME_COLLISION_IDENTICAL', name, realPaths, 'Copias idénticas byte a byte en rutas distintas.'));
    }
    for (const realPath of realPaths) {
      const aliases = members.filter((s) => s.realPath === realPath);
      if (aliases.length > 1) {
        findings.push(finding('SAME_REALPATH', name, [...aliases.map((s) => s.entryPath), realPath], 'Las entradas resuelven al mismo archivo canónico.'));
      }
    }
  }
  return groups;
}

function addPluginFindings(skills, findings) {
  const seen = new Set();
  for (const skill of skills) {
    if (!skill.plugin || skill.plugin.installed !== 'no') continue;
    const key = `${skill.plugin.id}/${skill.plugin.cacheVersion}`;
    if (seen.has(key)) continue;
    seen.add(key);
    findings.push(finding('PLUGIN_CACHE_NOT_INSTALLED', skill.plugin.id, [skill.entryPath],
      `La versión ${skill.plugin.cacheVersion} está en caché pero no figura como instalada en el registro.`));
  }
}
```

```js
export async function runSkills(ctx, limits = LIMITS) {
  const findings = [];
  if (!ctx.home) findings.push(finding('HOME_UNSET', 'HOME', [], `HOME ${ctx.homeProblem}; se omiten las raíces de usuario.`));
  const repoRoot = await findRepoRoot(ctx.fs, ctx.cwd);

    schemaVersion: 1,
    command: 'skills',
    tool: { ...TOOL },
    completeness: discovered.partial || !ctx.home ? 'partial' : 'complete',
    roots: discovered.roots,
    skills: inventory.skills,
    groups: inventory.groups,

      manifests: inventory.skills.length,
      uniqueFiles: new Set(inventory.skills.map((skill) => skill.realPath)).size,

      divergentNames: inventory.groups.filter((group) => group.status === 'divergent').length,

      warn: counts.warn,

  };
```

```js
import { cell, cleanDeep, tildify } from './sanitize.js';

export const NOTE = 'Nota: la presencia de un manifiesto no implica que el host cargue la skill.';
const COMPLETENESS = { complete: 'completo', partial: 'parcial', failed: 'fallido' };

// Único punto de saneamiento del JSON: el escapado de JSON.stringify no elimina controles.
export function renderJson(doc) {
  return `${JSON.stringify(cleanDeep(doc), null, 2)}\n`;
}

function row(values) {
  return values.map(cell).join('\t');
}

function pathFormatter(home) {
  return (path) => (path ? tildify(path, home) : null);
}

export function renderSkillsText(doc, home) {
  const p = pathFormatter(home);
  const s = doc.summary;
  const lines = [
    `jz-ai skills: ${s.roots} raíces (${s.rootsPresent} presentes), ${s.manifests} manifiestos, ${s.names} nombres, estado ${COMPLETENESS[doc.completeness]}`,
    NOTE,
    '',
    row(['NAME', 'HOST', 'ROOT', 'SHA256', 'LINK', 'PLUGIN', 'PATH']),
  ];
  for (const k of doc.skills) {
    lines.push(row([k.name, k.host, k.rootId, k.sha256 ? k.sha256.slice(0, 8) : null, p(k.linkTarget), pluginLabel(k.plugin), p(k.entryPath)]));
  }
  lines.push('', row(['SEVERITY', 'CODE', 'SUBJECT', 'MESSAGE', 'PATHS']));
  for (const f of doc.findings) lines.push(row([f.severity, f.code, f.subject, f.message, f.paths.map(p).join(' ')]));
  lines.push('', `resumen: info=${s.info} warn=${s.warn} error=${s.error}`);
  return `${lines.join('\n')}\n`;
}

function pluginLabel(plugin) {
  if (!plugin) return null;
  return `${plugin.id} ${plugin.cacheVersion} installed=${plugin.installed} enabled=${plugin.enabled} loaded=${plugin.loaded}`;
```

```js
import { parseArgs } from 'node:util';
import { createContext } from './context.js';
import { renderJson, renderSkillsText } from './render.js';
import { safeErrorCode } from './sanitize.js';
import { runSkills } from './skills.js';
import { TOOL } from './tool.js';

export const USAGE = `Uso: jz-ai <comando> [--json]
       jz-ai [<comando>] --help
       jz-ai --version

Comandos:
  doctor     Diagnóstico de herramientas, repositorio, rutas y entorno (solo lectura).
  skills     Inventario de manifiestos SKILL.md, procedencia y duplicados (solo lectura).

Opciones:
  --json     Salida JSON (schemaVersion 1).
  --help     Muestra esta ayuda (solo o tras un comando, sin otras opciones).
  --version  Muestra la versión (sólo como único argumento).
`;

const COMMANDS = {
  skills: { run: runSkills, text: renderSkillsText },
};

export async function run(argv, { stdout, stderr, ctx } = {}) {
  // Formas válidas: --help, <comando> --help y --version (spec §5). Se resuelven antes de crear el contexto.
  const helpRequested = (argv.length === 1 && argv[0] === '--help')
    || (argv.length === 2 && argv[1] === '--help' && Object.hasOwn(COMMANDS, argv[0]));
  if (helpRequested) {
    stdout.write(USAGE);
    return 0;
  }
  if (argv.length === 1 && argv[0] === '--version') {
    stdout.write(`${TOOL.name} ${TOOL.version}\n`);
    return 0;
  }
  let parsed;
  try {
    parsed = parseArgs({ args: argv, allowPositionals: true, strict: true, options: { json: { type: 'boolean' } } });
  } catch {
    return usageError(stderr, 'Opción o argumento inválido.');
  }
  const { values, positionals } = parsed;
  if (positionals.length !== 1 || !Object.hasOwn(COMMANDS, positionals[0])) return usageError(stderr, 'Comando inválido.');
  const name = positionals[0];
  const command = COMMANDS[name];
  const context = ctx ?? createContext();
  let doc;
  try {
    doc = await command.run(context);
  } catch (error) {
    // Nunca se publica error.message: puede contener rutas o fragmentos de archivos (spec §7.4).
    const code = safeErrorCode(error);
    const detail = code ? ` (${code})` : '';
    if (values.json) {
      stdout.write(renderJson({ schemaVersion: 1, command: name, tool: { ...TOOL }, completeness: 'failed', error: { code: 'INTERNAL', message: `Fallo interno inesperado${detail}.` } }));
    } else {
      stderr.write(`jz-ai ${name}: fallo interno inesperado${detail}.\n`);
    }
    return 3;
  }
  stdout.write(values.json ? renderJson(doc) : command.text(doc, context.home));
  return exitCodeFor(doc);
}

function usageError(stderr, message) {
  stderr.write(`${message}\n\n${USAGE}`);
  return 2;
}

export function exitCodeFor(doc) {
  const errors = doc.command === 'skills' ? doc.summary.error : doc.checks.filter((c) => c.severity === 'error').length;
  return doc.completeness === 'complete' && errors === 0 ? 0 : 1;
}
```

```js
import { execFile } from 'node:child_process';

export const GIT_PREFIX = ['--no-pager', '-c', 'core.fsmonitor=false', '-c', 'core.hooksPath=/dev/null'];

// Sin `status`: ejecuta filtros clean del repositorio (spec §10.1).
export const ALLOWED_GIT_ARGS = [
  ['--version'],
  ['rev-parse', '--abbrev-ref', 'HEAD'],
  ['rev-parse', '--verify', 'HEAD'],
];

export const GIT_CHILD_PATH = '/usr/bin:/bin';

// Entorno construido desde cero: nada del padre llega al hijo salvo el HOME ya validado.
export function gitEnv(home) {
  const out = {
    PATH: GIT_CHILD_PATH,
    LANG: 'C',
    LC_ALL: 'C',
    GIT_OPTIONAL_LOCKS: '0',
    GIT_TERMINAL_PROMPT: '0',
    GIT_CONFIG_NOSYSTEM: '1',
    GIT_CONFIG_GLOBAL: '/dev/null',
  };
  if (home) out.HOME = home;
  return out;
}

function isAllowed(args) {
  return ALLOWED_GIT_ARGS.some((allowed) => allowed.length === args.length && allowed.every((value, index) => value === args[index]));
}

export function createGitRunner({ gitPath, home, timeoutMs = 5000, maxBuffer = 1024 * 1024 }) {
  return function runGit(args, cwd) {
    if (!isAllowed(args)) return Promise.resolve({ ok: false, reason: 'not-allowed' });
    const fullArgs = args[0] === '--version' ? args : [...GIT_PREFIX, ...args];
    const options = { cwd, env: gitEnv(home), timeout: timeoutMs, maxBuffer, killSignal: 'SIGKILL', shell: false, windowsHide: true, encoding: 'utf8' };
    return new Promise((resolve) => {
      execFile(gitPath, fullArgs, options, (error, stdout) => {
        if (!error) return resolve({ ok: true, stdout });
        if (error.code === 'ERR_CHILD_PROCESS_STDIO_MAXBUFFER') return resolve({ ok: false, reason: 'output-too-large' });
        if (error.killed) return resolve({ ok: false, reason: 'timeout' });
        return resolve({ ok: false, reason: 'failed' });
      });
    });
  };
}
```

```js
export async function inspectRepo(runGit, repoRoot) {
  if (!repoRoot) {
    return { repo: { ...OUTSIDE }, checks: [check('repo.outside', 'El directorio actual no está dentro de un repositorio Git.')], partial: false };
  }
```

```js
import { check, sortChecks } from './findings.js';
import { inspectRepo, parseGitVersion } from './git.js';
import { compareBy } from './order.js';
import { envValue } from './context.js';
import { ENV_PRESENCE, PROVIDER_KEY_VARS, REPO_ENV_PATTERN, findRepoRoot, knownConfigPaths } from './paths.js';
import { TOOL } from './tool.js';

const MIN_NODE = [20, 19, 0];
const UNKNOWN_VERSION = Object.freeze({ value: null, confidence: 'unknown', source: null });

export async function runDoctor(ctx) {
  const checks = [];
  let partial = false;

  const nodeVersion = ctx.runtime.node.replace(/^v/, '');
  if (!atLeast(nodeVersion, MIN_NODE)) checks.push(check('runtime.node', `Node ${nodeVersion} es menor que 20.19.0.`));
  const isRoot = ctx.uid === 0;
  if (isRoot) checks.push(check('runtime.root', 'Proceso como root: los controles de jz-ai son de código, no un sandbox.'));
  if (!ctx.home) {
    partial = true;
    checks.push(check('env.home-unset', `HOME ${ctx.homeProblem}.`));
  }

  const tools = [];
  let runGit = null;
  // git nunca se busca en PATH: ruta fija validada (spec §10.1).
  const git = await inspectGit(ctx.fs, ctx.gitPath);
  if (git.status === 'missing') {
    tools.push(toolEntry('git', 'no', null, UNKNOWN_VERSION));
    checks.push(check('tool.git.missing', 'No existe git en la ruta fija admitida.'));
  } else if (git.status === 'untrusted') {
    tools.push(toolEntry('git', 'yes', git.path, UNKNOWN_VERSION));
    checks.push(check('tool.git.untrusted', 'git no es un archivo regular de root, ejecutable y sin escritura para grupo u otros; no se ejecuta.'));
  } else {
    runGit = ctx.createGitRunner(git.path);
    const result = await runGit(['--version'], '/');
    const value = result.ok ? parseGitVersion(result.stdout) : null;
    tools.push(toolEntry('git', 'yes', git.path, value ? { value, confidence: 'verified', source: 'git --version' } : UNKNOWN_VERSION));
    if (!value) checks.push(check('tool.git.version-unknown', 'No se pudo determinar la versión de git.'));
  }

  const pathDirs = (envValue(ctx.env, 'PATH') ?? '').split(':').filter((dir) => dir.startsWith('/'));
  tools.push(toolEntry('node', 'yes', null, { value: nodeVersion, confidence: 'verified', source: 'process.version' }));
  for (const name of ['claude', 'opencode']) {
    const found = await findExecutable(ctx.fs, name, pathDirs);
    if (!found) {
      tools.push(toolEntry(name, 'no', null, UNKNOWN_VERSION));
      checks.push(check(`tool.${name}.missing`, `${name} no está en PATH.`));
      continue;
    }
    const inferred = name === 'claude' ? inferClaudeVersion(found.realPath) : null;
    tools.push(toolEntry(name, 'yes', found.path, inferred ? { value: inferred, confidence: 'inferred', source: 'realpath' } : UNKNOWN_VERSION));
    if (!inferred) checks.push(check(`tool.${name}.version-unknown`, `Versión de ${name} no determinable sin ejecutarlo.`));
  }

  const repoRoot = await findRepoRoot(ctx.fs, ctx.cwd);
  let repo;
  if (runGit) {
    const inspected = await inspectRepo(runGit, repoRoot);
    repo = inspected.repo;
    checks.push(...inspected.checks);
    partial ||= inspected.partial;
  } else {
    repo = { inside: repoRoot ? 'yes' : 'no', root: repoRoot, branch: null, head: null, detached: 'unknown', workingTree: repoRoot ? 'not-inspected' : null };
    if (repoRoot) {
      partial = true;
      checks.push(check('repo.git-unavailable', 'No se inspeccionó el repositorio: no hay un git utilizable.'));
    } else {
      checks.push(check('repo.outside', 'El directorio actual no está dentro de un repositorio Git.'));
    }
  }

  const paths = await inspectPaths(ctx, repoRoot, checks);
  // Definida = propiedad propia con valor cadena, aunque esté vacía (spec §8).
  const env = ENV_PRESENCE.map((name) => ({ name, set: envValue(ctx.env, name) !== null ? 'yes' : 'no' }));
  if (PROVIDER_KEY_VARS.some((name) => envValue(ctx.env, name))) {
    checks.push(check('env.provider-keys', 'Hay claves de API definidas: llm-council elige proveedor según el entorno.'));
  }

  return {
    schemaVersion: 1,
    command: 'doctor',
    tool: { ...TOOL },
    completeness: partial ? 'partial' : 'complete',
    runtime: { node: ctx.runtime.node, platform: ctx.runtime.platform, arch: ctx.runtime.arch, uid: ctx.uid, isRoot },
    tools,
    repo,
    paths,
    env,
    checks: sortChecks(checks),
  };
}

function toolEntry(name, found, path, version) {
  return { name, found, path, version };
}

function atLeast(version, minimum) {
  const parts = version.split('.').map((part) => Number.parseInt(part, 10));
  for (let index = 0; index < minimum.length; index += 1) {
    const value = parts[index] ?? 0;
    if (value !== minimum[index]) return value > minimum[index];
  }
  return true;
}

export async function inspectGit(fs, gitPath) {
  let info;
  try {
    info = await fs.lstat(await fs.realpath(gitPath));
  } catch (error) {
    if (error.code === 'ENOENT' || error.code === 'ENOTDIR') return { status: 'missing', path: null };
    return { status: 'untrusted', path: gitPath };
  }
  const trusted = info.isFile() && (info.mode & 0o111) !== 0 && info.uid === 0 && (info.mode & 0o022) === 0;
  return { status: trusted ? 'ok' : 'untrusted', path: gitPath };
}

export async function findExecutable(fs, name, dirs) {
  for (const dir of dirs) {
    const path = join(dir, name);
    let realPath;
    try {
      realPath = await fs.realpath(path);
      const info = await fs.lstat(realPath);
      if (info.isFile() && (info.mode & 0o111) !== 0) return { path, realPath };
    } catch {
      continue;
    }
  }
  return null;
}

export function inferClaudeVersion(realPath) {

async function inspectPaths(ctx, repoRoot, checks) {
  const entries = knownConfigPaths(ctx.home, repoRoot);
  if (repoRoot) {
    let names = [];
    try {
      names = await ctx.fs.readdir(repoRoot);
    } catch {
      names = [];
    }
    for (const name of names) {
      if (REPO_ENV_PATTERN.test(name)) entries.push({ id: `repo-env:${name}`, path: join(repoRoot, name), category: 'secrets', sensitive: 'yes' });
    }
  }
  const results = [];
  for (const entry of entries) {
    const meta = await pathMetadata(ctx.fs, entry.path);
    results.push({
      id: entry.id, path: entry.path, category: entry.category, sensitive: entry.sensitive,
      exists: meta.exists, type: meta.type, mode: meta.mode, ownerUid: meta.ownerUid, contentRead: 'no',
    });
    if (meta.exists !== 'yes') continue;
    if (meta.type !== 'file') {
      checks.push(check(`paths.${entry.id}.unexpected-type`, `La ruta es de tipo ${meta.type}; se informa sin seguirla.`));
    } else if (entry.sensitive === 'yes' && (meta.modeBits & 0o077) !== 0) {
      checks.push(check(`paths.${entry.id}.permissive`, `Archivo sensible accesible por grupo u otros (modo ${meta.mode}).`));
    }
  }
  return results.sort(compareBy((item) => item.id));
}

async function pathMetadata(fs, path) {
  let info;
  try {
    info = await fs.lstat(path);
  } catch (error) {
    const exists = error.code === 'ENOENT' || error.code === 'ENOTDIR' ? 'no' : 'unknown';
    return { exists, type: null, mode: null, ownerUid: null, modeBits: 0 };
  }
  const type = info.isFile() ? 'file' : info.isDirectory() ? 'directory' : info.isSymbolicLink() ? 'symlink' : 'other';
  const modeBits = info.mode & 0o7777;
  return { exists: 'yes', type, mode: modeBits.toString(8).padStart(4, '0'), ownerUid: info.uid, modeBits };
}
```
